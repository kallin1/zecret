# ZeCret 시연 시나리오

## 짧은 시연 대본 (읽기용)

먼저 성남 서울공항 제한보호구역과 남한산성 국가유산이 겹치는 좌표(127.1567, 37.4504)에 높이 20미터로 검색해보겠습니다. *(검색 클릭)* 반경 내 시설 stat tile에 2건이 뜨고, 일조권과 국가유산은 위반, 군사시설은 제9조·제10조 두 항목 모두 적합으로 나옵니다. 지도에는 계획 건물 위치 마커와 함께 실제 성남시 건물 배경, 그리고 인접 시설의 정확한 위치 대신 격자 단위 위험도만 표시됩니다.

이제 높이만 65미터로 올려서 다시 검색하겠습니다. *(검색 클릭)* 군사시설 항목이 이번엔 제9조(45m 기준)·제10조(60m 기준) 두 개 다 위반으로 바뀝니다. 이 두 숫자는 코드 어디에도 평문으로 존재하지 않습니다. 그런데도 위반으로 정확히 판정됩니다 — 동형암호 뺄셈 결과를 관리기관이 복호화해서 부호만 돌려준 겁니다.

다음은 먼 좌표(130.0, 35.0)로 검색해보겠습니다. *(검색 클릭)* 일조권만 남고 군사시설·국가유산 항목 자체가 사라집니다. 국가유산은 1km, 군사시설은 시설 유형별 반경(서울공항처럼 전술항공작전기지는 5km, 군사기지법 제5조 근거) 안에 있는 시설만 판정 대상에 포함하기 때문입니다.

마지막으로 채팅창에 "정확히 어떤 조문을 위반했나요"라고 물어보겠습니다. Claude API 키가 설정되어 있으면 LLM이 판정을 다시 계산하는 대신 실제 tool(`get_violation_citations`)을 스스로 호출해 RAG에서 조문 원문을 찾아오고, 그 반환값만 근거로 답합니다.

이상으로 시연을 마치겠습니다.

---

> 사전 준비: `python scripts/generate_mock_ciphertexts.py` 실행 후(암호문 캐시 생성) `streamlit run app.py`로 대시보드 기동.
> 아래 입력값은 실제 코드의 샘플 데이터(`src/compliance/config.py`, `docs/baseline_phase5.json`)와 정확히 일치하는 값이라 결과가 그대로 재현됩니다.

## 시연 1 — 3개 규제(+2개 군사 테마)가 동시에 걸리는 위치 (기본 케이스)

**입력값**

| 항목 | 값 |
|---|---|
| 경도 (X) | `127.1567` |
| 위도 (Y) | `37.4504` |
| 계획 높이 (m) | `20.0` |
| 이격거리 (m) | `3.0` |

**예상 결과**: 반경 내 시설 stat tile = `2`(국가유산 1 + 군사시설 1). 일조권 사선제한 위반 / 국가유산(남한산성) 위반 / 군사시설(서울공항) 제9조·제10조 모두 적합 — 판정 항목 stat tile = `4`

**말할 내용**
> "서울공항 군사시설보호구역과 남한산성 역사문화환경보존지역이 겹치는 좌표를 입력하고, 계획 높이는 20미터로 넣어보겠습니다. 검색을 누르면 반경 내 시설 개수가 먼저 뜨고, 이어서 카테고리·규정 테마별로 총 4개 항목이 판정됩니다.
> 지도를 보시면 계획 건물 위치 마커와 실제 성남시 건물 배경(2.5D)이 함께 뜨고, 인접한 군사시설·국가유산은 정확한 위치 대신 격자 단위 위험도로만 표시됩니다 — 이게 저희가 말씀드린 '정밀 좌표 대신 격자 단위' 시각화 원칙입니다.
> 결과를 보면 일조권과 국가유산은 위반, 군사시설은 제9조·제10조 두 항목 모두 적합입니다. 같은 서울공항이라도 법적 근거(제9조 제한보호구역/제10조 비행안전구역)가 두 개라 각각 독립적으로 판정하고, 둘 다 서버가 원본 높이제한값을 복호화한 적이 없습니다 — 암호문 뺄셈 결과의 부호만 관리기관 검증 API를 거쳐 받아온 겁니다."

## 시연 2 — 같은 위치, 높이만 올려서 군사시설 두 테마 모두 위반시키기

**입력값**

| 항목 | 값 |
|---|---|
| 경도 (X) | `127.1567` |
| 위도 (Y) | `37.4504` |
| 계획 높이 (m) | `65.0` |
| 이격거리 (m) | `3.0` |

**예상 결과**: 일조권 위반 / 국가유산 위반 / 군사시설 제9조(기준 45m 초과)·제10조(기준 60m 초과) 모두 위반 — 판정 항목 `4`, 위반 `4`

**말할 내용**
> "이번엔 높이만 65미터로 올려보겠습니다. 군사시설 기준은 제9조 45미터, 제10조 60미터인데, 서버는 이 두 숫자를 코드 어디에도 갖고 있지 않습니다. 그런데도 판정은 정확하게 두 항목 모두 '위반'으로 나옵니다. 이게 동형암호 뺄셈 결과를 관리기관 쪽에서 복호화해서 부호만 돌려주는 구조가 실제로 동작한다는 증거입니다."

*(선택: 여유가 있으면 여기서 `pytest tests/test_information_exposure.py -v` 를 터미널로 한 번 실행해, 군사시설 결과의 margin이 항상 None인지 자동 검증되고 있음을 짧게 보여줘도 좋음.)*

## 시연 3 — 반경 밖 위치로 "범위 검색" 시연

**입력값**

| 항목 | 값 |
|---|---|
| 경도 (X) | `130.0` |
| 위도 (Y) | `35.0` |
| 계획 높이 (m) | `8.0` |
| 이격거리 (m) | `1.0` |

**예상 결과**: 반경 내 시설 stat tile = `0`. 일조권만 위반으로 표시 (군사시설·국가유산 항목 자체가 나타나지 않음)

**말할 내용**
> "이번엔 아까와 완전히 다른 위치, 남쪽 먼 좌표를 넣어보겠습니다. 일조권 사선제한은 이격거리만 있으면 어디서든 적용되는 전국 공통 기준이라 여전히 판정되지만, 군사시설과 국가유산은 아예 결과 목록에 나타나지 않습니다. 이게 체크포인트 ②번, '범위 검색'입니다 — 국가유산은 1km, 군사시설은 시설 유형별 반경(서울공항 같은 전술항공작전기지는 군사기지법 제5조 근거로 5km)을 각각 적용해서, 반경 밖이면 애초에 조회조차 하지 않습니다."

## 시연 4 — LLM 챗봇으로 실제 tool-calling 근거 질의

시연 1 또는 2 결과가 화면에 남아 있는 상태에서 하단 채팅창에 아래 질문을 입력.

**입력 질문 (예시)**
> "정확히 어떤 조문을 위반했나요?"

**말할 내용**
> "이제 아래 채팅창에 '정확히 어떤 조문을 위반했나요'라고 물어보겠습니다. `ANTHROPIC_API_KEY`가 설정돼 있으면, Claude가 판정을 다시 계산하는 게 아니라 실제로 `get_violation_citations`라는 tool을 스스로 호출해서 RAG 벡터DB에서 조문 원문을 찾아오고, 그 결과만 근거로 답합니다 — 판정을 재실행하는 tool은 채팅에서 아예 노출하지 않기 때문에, 좌표나 높이를 다시 계산하는 일도 없습니다. 키가 없거나 tool-calling이 실패하면 report+RAG 근거를 프롬프트에 채우는 단발 호출로, 그것도 실패하면 규칙 기반 답변으로 자동 대체됩니다 — 어느 경로든 LLM이 판정 결과를 지어낼 여지가 없습니다. 이게 저희 다섯 번째 원칙입니다."

*(LLM 응답은 그 순간의 tool-calling/fallback 상태에 따라 문구가 조금 달라질 수 있음 — 답변에 근거 조문(군사기지법 제9·10조, 건축법 제61조 등)이 언급되면 성공.)*

## 시연 순서 요약 (타임박스)

| 순서 | 내용 | 강조 체크포인트 | 예상 시간 |
|---|---|---|---|
| 1 | 20m 입력 → 반경 내 시설 2건 + 4개 항목 동시 판정 | ①③ 암호화 저장·시각화 대안(격자+2.5D 배경) | 45초 |
| 2 | 65m으로 재검색 → 군사시설 두 테마 모두 위반 전환 | ①②HE 정확성, 규정 테마 분리 | 30초 |
| 3 | 먼 좌표로 재검색 → 일조권만 남음 | ②범위 검색(시설 유형별 반경) | 25초 |
| 4 | 챗봇에 근거 조문 질문 (실제 tool-calling) | ⑤LLM 임의응답 금지 | 30초 |

**주의사항**
- 사이드바는 폼(form)이라 값을 바꿔도 자동 반영되지 않고 반드시 "🔍 검색" 버튼을 다시 눌러야 함 — 시연 중 버튼 클릭을 빠뜨리지 않도록 주의.
- margin(위반 폭 같은 정밀 수치)은 화면 어디에도 렌더링되지 않으므로, "왜 여유분/부족분 숫자가 안 보이냐"는 질문이 나오면 "군사시설 대상은 원칙상 margin 자체를 절대 노출하지 않기 때문"이라고 답하면 됨.
- 지도에 실제 건물 배경(2.5D)을 보려면 `VWORLD_API_KEY`가 필요하고, 건물통합정보 WFS 응답 스키마는 실 키로 검증 전이라 높이/층수 속성이 없으면 평면으로 폴백함 — 배경이 안 보여도 판정 기능 자체에는 영향 없음.
