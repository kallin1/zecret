# ZeCret 시연 시나리오

## 짧은 시연 대본 (읽기용)

먼저 성남 서울공항과 남한산성 인근 좌표(127.125, 37.126)에 높이 20미터로 검색해보겠습니다. *(검색 클릭)* 일조권과 국가유산은 위반, 군사시설은 적합으로 나오고, 지도에는 계획 건물 위치 하나만 표시됩니다.

이제 높이만 50미터로 올려서 다시 검색하겠습니다. *(검색 클릭)* 군사시설 기준은 45미터인데, 이 숫자는 코드 어디에도 평문으로 존재하지 않습니다. 그런데도 위반으로 정확히 판정됩니다 — 동형암호 뺄셈 결과를 관리기관이 복호화해서 부호만 돌려준 겁니다.

다음은 먼 좌표(130.0, 35.0)로 검색해보겠습니다. *(검색 클릭)* 일조권만 남고 군사시설·국가유산 항목 자체가 사라집니다. 반경 1킬로미터 안에 있는 시설만 판정 대상에 포함하기 때문입니다.

마지막으로 채팅창에 "어떤 법령을 위반했나요"라고 물어보겠습니다. LLM은 판정을 다시 계산하지 않고, 이미 확정된 결과와 근거 조문만 받아 요약해서 답합니다.

이상으로 시연을 마치겠습니다.

---

> 사전 준비: `python scripts/generate_mock_ciphertexts.py` 실행 후(암호문 캐시 생성) `streamlit run app.py`로 대시보드 기동.
> 아래 입력값은 실제 코드의 샘플 데이터(`src/compliance/config.py`, `docs/baseline_phase5.json`)와 정확히 일치하는 값이라 결과가 그대로 재현됩니다.

---

## 시연 1 — 3개 규제가 동시에 걸리는 위치 (기본 케이스)

**입력값**

| 항목 | 값 |
|---|---|
| 경도 (X) | `127.125` |
| 위도 (Y) | `37.126` |
| 계획 높이 (m) | `20.0` |
| 이격거리 (m) | `3.0` |

**예상 결과**: 일조권 사선제한 위반 / 국가유산(남한산성) 위반 / 군사시설(성남 서울공항) 적합

**말할 내용**
> "성남 서울공항 비행안전구역과 남한산성 역사문화환경보존지역 근처 좌표를 입력하고, 계획 높이는 20미터로 넣어보겠습니다. 검색을 누르면 세 카테고리가 동시에 판정됩니다.
> 지도를 보시면 계획 건물 위치 마커 하나만 찍혀 있고, 인접한 군사시설이나 국가유산의 실제 위치는 지도에 전혀 표시되지 않습니다 — 이게 저희가 말씀드린 '격자 단위가 아니라 아예 위치 자체를 안 그린다'는 시각화 원칙입니다.
> 결과를 보면 일조권과 국가유산은 위반으로 나오고, 군사시설은 적합으로 나옵니다. 여기서 주목해주실 부분은, 세 배지가 화면상으로는 똑같이 생겼지만 내부적으로는 다르다는 겁니다 — 군사시설 판정은 지금 이 순간에도 서버가 원본 높이제한값을 복호화한 적이 없고, 암호문 뺄셈 결과의 부호만 관리기관 검증 API를 거쳐 받아온 겁니다."

## 시연 2 — 같은 위치, 높이만 올려서 군사시설도 위반시키기

**입력값**

| 항목 | 값 |
|---|---|
| 경도 (X) | `127.125` |
| 위도 (Y) | `37.126` |
| 계획 높이 (m) | `50.0` |
| 이격거리 (m) | `3.0` |

**예상 결과**: 일조권 위반 / 국가유산 위반 / 군사시설 위반 (기준 45m 초과)

**말할 내용**
> "이번엔 높이만 50미터로 올려보겠습니다. 군사시설 기준은 45미터인데, 서버는 이 45라는 숫자를 코드 어디에도 갖고 있지 않습니다 — 방금 보여드린 `src/compliance/config.py`에도 좌표만 있지 높이제한 숫자는 없죠. 그런데도 판정은 정확하게 '위반'으로 나옵니다. 이게 동형암호 뺄셈 결과를 관리기관 쪽에서 복호화해서 부호만 돌려주는 구조가 실제로 동작한다는 증거입니다."

*(선택: 여유가 있으면 여기서 `pytest tests/test_information_exposure.py -v` 를 터미널로 한 번 실행해, 군사시설 결과의 margin이 항상 None인지 자동 검증되고 있음을 짧게 보여줘도 좋음.)*

## 시연 3 — 반경 밖 위치로 "범위 검색" 시연

**입력값**

| 항목 | 값 |
|---|---|
| 경도 (X) | `130.0` |
| 위도 (Y) | `35.0` |
| 계획 높이 (m) | `8.0` |
| 이격거리 (m) | `1.0` |

**예상 결과**: 일조권만 위반으로 표시 (군사시설·국가유산 항목 자체가 나타나지 않음)

**말할 내용**
> "이번엔 아까와 완전히 다른 위치, 남쪽 먼 좌표를 넣어보겠습니다. 일조권 사선제한은 이격거리만 있으면 어디서든 적용되는 전국 공통 기준이라 여전히 판정되지만, 군사시설과 국가유산은 아예 결과 목록에 나타나지 않습니다. 이게 체크포인트 ②번, '범위 검색'입니다 — 계획 위치를 중심으로 1킬로미터 반경 안에 있는 시설만 인접 시설로 판단해서 판정 대상에 포함시키고, 반경 밖이면 애초에 조회조차 하지 않습니다."

## 시연 4 — LLM 챗봇으로 근거 질의

시연 1 또는 2 결과가 화면에 남아 있는 상태에서 하단 채팅창에 아래 질문을 입력.

**입력 질문 (예시)**
> "어떤 법령을 위반했나요?"

**말할 내용**
> "이제 아래 채팅창에 '어떤 법령을 위반했나요'라고 물어보겠습니다. 여기서 LLM은 판정을 다시 계산하는 게 아니라, 방금 그래프가 이미 확정한 위반/적합 결과와 RAG로 검색된 조문 근거만 받아서 그걸 설명하는 역할만 합니다. 그래서 LLM이 '아마 이럴 것이다'라고 추측해서 답을 지어낼 여지가 원천적으로 없습니다 — 이게 저희 다섯 번째 원칙입니다."

*(LLM 응답은 그 순간의 fallback/API 상태에 따라 문구가 조금 달라질 수 있음 — 답변에 근거 조문(건축법 제61조 등)이 언급되면 성공.)*

## 시연 순서 요약 (타임박스)

| 순서 | 내용 | 강조 체크포인트 | 예상 시간 |
|---|---|---|---|
| 1 | 20m 입력 → 3개 카테고리 동시 판정 | ①③ 암호화 저장·시각화 대안 | 40초 |
| 2 | 50m으로 재검색 → 군사시설도 위반 전환 | ①②HE 정확성 | 30초 |
| 3 | 먼 좌표로 재검색 → 일조권만 남음 | ②범위 검색 | 25초 |
| 4 | 챗봇에 근거 질문 | ⑤LLM 임의응답 금지 | 25초 |

**주의사항**
- 사이드바는 폼(form)이라 값을 바꿔도 자동 반영되지 않고 반드시 "🔍 검색" 버튼을 다시 눌러야 함 — 시연 중 버튼 클릭을 빠뜨리지 않도록 주의.
- margin(위반 폭 같은 정밀 수치)은 화면 어디에도 렌더링되지 않으므로, "왜 여유분/부족분 숫자가 안 보이냐"는 질문이 나오면 "군사시설 대상은 원칙상 margin 자체를 절대 노출하지 않기 때문"이라고 답하면 됨.
